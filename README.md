# Ника - помощник волейбольных команд

Я сделала Нику для игроков и родителей команд «Ника-Восток» и «Ника-Юго-Восток». В чате можно узнать, когда и где будет матч, с кем играет команда, когда проходит тренировка и кто тренер.

## Как запустить

1. Скачайте файлы проекта и откройте папку с `app.py` в VS Code.
2. Откройте терминал и выполните:

   ```powershell
   python -m pip install -r requirements.txt
   python -m streamlit run app.py
   ```

3. Откройте адрес, который появится в терминале. Обычно это `http://localhost:8501`.

Для ответов через нейросеть нужна запущенная Ollama. Если модель ещё не скачана, выполните:

```powershell
ollama pull qwen3:1.7b
```

## Как работает Ника

Если я спрашиваю «Кто мой тренер?», Ника сначала уточняет команду, группу и год рождения. Когда я отвечаю «Ника Восток, 2010, мальчики», она возвращается к исходному вопросу и ищет тренера в базе. В рамках одного диалога эти данные сохраняются. Кнопка «Новый диалог» очищает их.

Для вопросов о матчах, тренировках и тренерах Ника берёт факты из файлов проекта, а Ollama формулирует ответ. На общий вопрос вроде «Что такое волейбол?» может ответить сама модель. Если Ollama недоступна, Ника показывает готовый ответ из базы, когда он есть. Для общего вопроса она сообщает о сбое. Оба случая отмечаются в журнале.

Жалобы, сообщения о травмах и заявки на запись попадают в раздел «Обращения для администратора». Ника предлагает обратиться к тренеру или администрации.

## Журнал и проверка

Команда `/report` показывает, сколько обращений обработано, сколько было в каждой категории и сколько передано человеку. В `events.jsonl` сохраняются время, категория и действие. Текст сообщений и личные данные в журнал не записываются.

В разделе «Обращения для администратора» можно скачать CSV. Чтобы узнать время обработки, нужно найти строки «получено» и «обработано» с одинаковым `case_id` и сравнить их отметки времени.

После того как в журнале появятся записи, целостность хэш-цепочки можно проверить командой:

```powershell
python verify_log.py events.jsonl
```

Для запуска автотестов:

```powershell
python -m unittest -v
```

## Основные файлы

| Файл | Что в нём |
|---|---|
| `app.py` | Интерфейс чата, команда `/report`, очередь и выгрузка CSV |
| `agent.py` | Логика ответов, уточнения и подключение Ollama |
| `classifier.py` | Определение категории обращения |
| `match_location.py` | Поиск места проведения матча |
| `knowledge.json` | База из 21 вопроса и ответа |
| `schedule.json`, `teams.json` | Матчи, тренировки, тренеры и залы |
| `event_log.py` | Запись событий, сводка и экспорт CSV |
| `hash_chain.py`, `verify_log.py` | Хэш-цепочка и проверка журнала |
| `test_agent.py`, `TESTS.md` | Автотесты и тест-план |

Проект выполнен для дисциплины «Основы бизнес-информатики». Имена и адреса в базе вымышлены по условию задания.
